# Test Generator Skill

## Descripción

Genera automáticamente tests unitarios y de integración siguiendo los patrones del proyecto. Crea fixtures, mocks y assertions apropiadas para cada tipo de módulo.

## Activación

```
Genera tests para [módulo]
```
